├── index.html

Keep any additional product images or assets referenced by index.html or products.json in the published repository, using the correct paths and filenames. If your current repository uses a different folder structure, retain that structure and update the paths accordingly.
🌐 Deploy with GitHub Pages
1. Open the GitHub repository that contains the FitVerse_Finds website.
2. Add the website HTML file and rename it to index.html if it is the site's main page.
3. Add products.json, the logo, and any required image assets to the appropriate published directory.
4. Commit and push your changes to GitHub.
5. In the repository, open Settings → Pages.
6. Select the branch and folder containing index.html as the publishing source, then save.
7. Wait for GitHub Pages to publish the site and open the URL shown in the Pages settings.
8. Test the site on both desktop and mobile, including product images, shopping links, and product-management features.
For official instructions, see the GitHub Pages documentation.
🛍️ Updating Products
The website uses products.json for its product catalogue.
1. Open products.json in your repository.
2. Add or edit product entries while preserving the JSON structure already used by the website.
3. Check product names, image paths, prices, descriptions, and affiliate URLs for accuracy.
4. Commit the changes to GitHub.
5. Refresh the live website and confirm that the updated products appear.
Important: Valid JSON is required. A missing comma, unmatched quote, or incorrect image path can prevent product data from displaying correctly.

The website also includes GitHub-based product-management functionality. Follow the website's own setup flow for that feature, and test changes in the live published site after saving.
🔐 Security Notes
- Never publish a GitHub personal access token in this README, source code, screenshots, public issues, or a public repository.
- Use the minimum permissions required for the intended GitHub operation.
- If a token is exposed, revoke it and create a replacement.
- Remember that a static website's client-side code is visible to visitors. Do not put private credentials or server-side secrets in it.
